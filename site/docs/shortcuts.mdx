---
title: Keyboard shortcuts
description: The keys, as a JetBrains IDE has them.
---

| keys                                   | does                |
| -------------------------------------- | ------------------- |
| <kbd>⇧</kbd> <kbd>⇧</kbd>              | Search Everywhere   |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> | Go to endpoint      |
| <kbd>⌘</kbd> <kbd>⏎</kbd>              | Run the query       |
| <kbd>⌘</kbd> <kbd>R</kbd>              | Run it again        |
| <kbd>⌘</kbd> <kbd>S</kbd>              | Save the query      |
| <kbd>⌘</kbd> <kbd>W</kbd>              | Close the tab       |
| <kbd>⌘</kbd> 1–9                       | The tabs in order   |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>I</kbd> | Trace an ID         |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>M</kbd> | The service map     |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> | Find in the results |
| <kbd>⌥</kbd> <kbd>F12</kbd>            | The terminal        |
| <kbd>⌘</kbd> <kbd>,</kbd>              | Settings            |

Click a button with a shortcut three times and Flux tells you the keys, once.
