---
title: Install
description: Download Flux, open it once, and let it update itself from then on.
---

<Steps>
  <Step title="Download">
    Get the latest `.dmg` from [flux.emreb.dev/download](https://flux.emreb.dev/download), drag Flux to `/Applications` and open it. Flux is a
    universal build: Apple silicon and Intel, macOS 13 or later, signed with an Apple Developer ID and notarized by Apple, so macOS opens it like any
    other app.
  </Step>
  <Step title="Sign in">
    Flux asks you to sign in with an email link or code, or with GitHub or Google. The account holds only your synced preferences; see [Where your
    data lives](/data).
  </Step>
</Steps>

## Updates

Flux checks for a new version at launch and every hour. A new version is offered a few minutes after it is published, and installs with one click; Flux reopens where you left it. When an old version can no longer be used, Flux asks for the update before anything else.
